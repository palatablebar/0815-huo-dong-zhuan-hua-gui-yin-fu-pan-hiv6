# 活动转化归因复盘

营销数据分析员可在工作台上传来源 CSV，对照规则判断差异，签发合格批次或记录暂缓意见。

对已授权触点按 event-time 窗口做多触点等分归因：同意且在回溯窗口内的非直达触点
共同参与，同一笔净额按触点等分（整数分按记录键补齐），渠道功劳逐条与净额对平；
直达记录与无触点案例单独列示，并作为未对平项留出记录键。同一来源重跑不新增功劳，
来源更新只重算受影响转化并保留旧版证据；冲突、窗口缺口与未对平时挡住签发。

## 启动

```sh
docker compose up --build -d --wait
```

打开 <http://localhost:18309>。页面预览带异常样例。选中阶段查看计算证据，用“归因账 / 直达记录 / 无触点案例 / 阻断项”分页核对，
选择可签发样例执行批次，然后提交复核意见。

## 核验

```sh
docker compose exec -T app pytest -q
```
